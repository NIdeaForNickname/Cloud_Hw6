1. Зарегистрироваться на Microsoft Azure. Получить free trial. Для регистрации вы можете использовать студенческие учетные записи Microsoft. Скриншот успешной регистрации https://azure.microsoft.com/ru-ru

2.
В сервисе DynamoDB создайте таблицу Пользователей
Напишите консольную программу на C#, которая загружает информацию из таблицы Пользователит в DynamoDB и записывает информацию о студентах в текстовый файл.
 
Обратите внимание, что в файл необходимо записать данные о студентах в текстовом формате, а не в JSON.
 
Реузльтат отправьте в личные сообщение в тимс C#-файл с кодом и текстовый файл с данными о студентах+ скрин.
